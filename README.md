## 🛠️ Requirements

* C++17 or later
* Any C++ compiler (GCC, MinGW, MSVC, Clang)

## ▶️ Compile & Run

Compile:

```bash
g++ filename.cpp -o output
```

Run:

### Windows

```bash
output.exe
```

### Linux / macOS

```bash
./output
```
